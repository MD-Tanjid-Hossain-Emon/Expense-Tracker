# Daily Expense Calculator

A simple web app for tracking daily expenses and calculating the monthly total.

## Files

- `index.html` - app structure and page content.
- `styles.css` - styling for the page.
- `script.js` - JavaScript logic for adding expenses and computing totals.

## Usage

1. Open `index.html` in a browser.
2. Add a date, amount, and category.
3. The app displays daily items and updates the monthly total automatically.
